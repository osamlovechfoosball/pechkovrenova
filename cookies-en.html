Cookie Policy

Cookies are small text files that a website may store in a visitor's browser. They can be used for technical site operation, remembering preferences or statistics.

What cookies this website uses

In its current version, the Pechkov Renova website does not use advertising, analytics or tracking cookies. Google Analytics, Meta Pixel or another marketing system has not been added.

Is a cookie banner needed?

Because the website does not place non-essential cookies, a consent banner has not been added. If analytics, advertising pixels, chat tools or other external services are added in the future, this policy must be updated and a prior consent mechanism must be added where required.

Technical data

The hosting provider may process technical logs such as IP address, date, time, browser and requested files for security and normal site operation. This data is not used by Pechkov Renova for behavioral advertising.

Changes

If the website technologies change, this page should be updated to reflect the cookies and external services actually used.

Browser storage and external links

The current website code does not set cookies or write data to localStorage, sessionStorage or IndexedDB. Language selection opens a separate page. The menu, gallery and expandable services do not require tracking cookies.

The Viber and WhatsApp buttons link to external services; they are not embedded chats. Once opened, those services may use cookies and other technologies under their own policies. The same applies to an application selected from your device's sharing menu.

You can manage cookies, history and saved data in your browser settings. Ordinary caching of images and styles differs from a tracking cookie. The actual hosting configuration may introduce technical services that need checking when the website is published or the provider changes.

For inquiry processing, see the Privacy Policy.
